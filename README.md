# 🌐 Minicurso Perfil Dev

Este é um projeto de site/perfil profissional desenvolvido durante o minicurso de desenvolvimento web, cobrindo desde a estruturação do código até o versionamento e publicação na nuvem.

🔗 **Acesse o site rodando ao vivo:** [minicurso-perfil-dev-eight.vercel.app](https://minicurso-perfil-dev-eight.vercel.app)

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação semântica da página.
- **CSS3:** Estilização, layout, personalização e **media queries para responsividade**.
- **JavaScript:** Funcionalidades dinâmicas e interatividade.
- **Git & GitHub:** Versionamento de código e controle de versões.
- **Vercel:** Hospedagem e deploy contínuo integrado ao GitHub.

---

## 📱 Responsividade

O projeto foi ajustado com **Media Queries** no CSS para garantir uma boa visualização em telas de celulares e dispositivos móveis (telas de até 600px de largura).
